# Portfolio title

Assistly — AI Customer Support Chatbot & Help Center

# Short description

A responsive customer support workspace that combines a polished chat interface, searchable help articles, and optional Gemini AI assistance. Built with React and Flask, with light and dark themes, saved conversations, and downloadable transcripts.

# Project description

Assistly is a concept project designed to make online customer support feel clear, approachable, and easy to navigate. I upgraded a basic React and Flask chatbot into a branded support workspace with a cohesive visual system, thoughtful microcopy, and layouts that adapt to desktop and mobile screens.

The experience includes suggested conversation starters, a searchable help center, keyboard-friendly controls, persistent chat history, transcript downloads, and clear recovery when the AI service is unavailable. A scripted sample mode lets visitors explore the experience without an API key. An optional server-side Gemini integration supports open-ended AI conversations while keeping credentials out of the browser.

The result is an editable, demonstrable support interface suitable for showcasing UI design and chatbot development. All business policies and support scenarios are fictional. Order lookup, real refunds, and agent transfer are outside the demo scope.

# Skills demonstrated

React development · Python/Flask APIs · Conversational UX · Responsive UI design · Gemini API integration · Accessibility basics · State persistence · Error handling
